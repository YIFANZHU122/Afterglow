# Afterglow 角色构筑首版数值记录

本文记录计划039首版可调参数。代码负责规则和安全边界，后续平衡调整优先修改本记录并同步测试，不在场景脚本复制数值。

## 属性

| 属性 | 每点效果 | 硬上限 |
|---|---:|---:|
| 智力 | 制作耗时 -3%；普通配方材料折扣 +3%，总折扣最多15% | 20点 |
| 力量 | 近战伤害 +4%；负重上限 +2；采集/挖掘耗时 -2% | 20点 |
| 体力 | 最大生命 +4；最大体力 +6；体力恢复 +1% | 20点 |

新局分配点为10点，必须全部分配后才能确认；确认后本局内锁定。

## 背包与负重

- 基础背包8格；普通背包+2格；大型背包+4格。
- 基础负重上限20；力量和装备提供加成。
- 装备栏不占普通背包格，也计入负重。

| 当前重量 / 上限 | 移速倍率 | 体力消耗倍率 | 行动限制 |
|---:|---:|---:|---|
| ≤100% | 1.00 | 1.00 | 正常 |
| 100–110% | 0.90 | 1.10 | 正常 |
| 110–125% | 0.80 | 1.25 | 可奔跑 |
| 125–140% | 0.65 | 1.50 | 禁止奔跑 |
| >140% | 0.50 | 2.00 | 禁止奔跑、翻越、游泳 |

## 叠加顺序

最终属性按以下顺序解析：基础值 → 属性加算 → 装备加算/修正 → 局内 Buff 乘算 → 负重惩罚乘算。玩家和 UI 不直接拼接同一数值。

## 首版装备资源

头、甲、裤、包四槽各提供轻重两件灰盒装备，装备效果由 `EquipmentDefinition` 明确字段描述，不从名称或贴图推断。更换装备需要后续交互层接入2秒站定和受击中断规则。
