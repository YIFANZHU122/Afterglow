# 测试与验收规范

## 1. 每次变更

必须执行相关单元/逻辑测试、GDScript 语法或静态检查、必要的 Godot 场景运行验证和 Git diff 检查。测试命令、工作目录和结果必须写入报告。

## 2. 核心规则覆盖

涉及生命/死亡/复活、伤害、资源消耗、层间推进、驻留惩罚、安全区、Boss、难度或存档时，至少覆盖正常流程、边界值、空数据、重复调用、非法状态、资源不足和失败恢复。

## 3. 场景验证

涉及场景、节点、资源或输入时，除逻辑测试外必须验证实际加载和关键交互。环境不可用时标记 `not-run` 并记录原因，不得写成通过。

## 4. 失败报告

任何失败都必须报告失败项、现象、初步根因、已修复/未修复状态和剩余风险。未验证的部分不能归入“完成”。
