# AI 任务执行规范

## 1. 任务开始

读取总规范和相关专项规范，检查 Git 状态，定位已有实现和测试，判断任务级别，写出目标、范围、非目标、影响模块和验收标准。

## 2. 小任务

可以直接执行，但不得改公共接口、核心规则或无关模块；必须补测试并报告。

## 3. 计划任务

大任务、跨模块、高风险任务先创建计划文档并登记索引。执行期间同步更新状态、任务勾选、风险和验证记录；只有满足验收标准才标记完成。

## 4. 修改边界

不擅自引入插件、依赖、Autoload、公共接口、存档字段或网络抽象。不确定时保守停在分析并把不确定性写入计划，而不是用猜测实现。

## 5. 完成报告

报告必须包含：任务分类、计划路径、修改文件、接口/数据变化、测试和 Godot 验证、diff 检查、风险、遗留问题和结论。AI 不得以“代码写完”代替“验证完成”。
