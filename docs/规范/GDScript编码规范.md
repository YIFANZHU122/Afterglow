# GDScript 编码规范

## 1. 类型与结构

- 使用 Godot 4.7.1 支持的静态类型；变量、参数、返回值和信号参数尽量显式声明。
- 一个脚本只有一个主要职责；超过职责边界时拆分服务、组件或纯逻辑类。
- 公共方法只暴露稳定意图，不暴露内部容器供调用方直接修改。
- 复杂计算拆成可测试的小函数；避免深层嵌套和重复规则。

## 2. 命名

- 类名：`PascalCase`。
- 变量、函数、信号：`snake_case`。
- 常量：`UPPER_SNAKE_CASE`。
- 私有成员使用项目统一的私有命名约定，不能借命名掩盖未经说明的公共接口。
- 文件名与主要类/职责一致，避免 `utils.gd`、`manager.gd` 等无语义名称。

## 3. 代码规则

- 用常量替代魔法数字和字符串。
- 优先使用明确类型或专用 Resource/类，不用大型无约束 Dictionary 代替领域模型。
- 不用 `get_node("../../...")` 作为跨模块主通信方式。
- 不通过字符串拼接调用方法，不依赖隐式 Autoload，不在 `_process` 中堆积所有业务逻辑。
- 注释解释原因、约束和非显然决策，不重复代码表面语义。
- 修改公共签名必须说明调用方、兼容策略和测试。
