# 计划039 角色构筑阶段交接记录

## 当前状态

计划039已于 2026-09-01 完成验收，后续开发可从计划040继续。

## 已完成

- 新增 `CharacterAttributesModel`：10点分配、三属性上限20、确认锁定、快照校验。
- 新增 `EquipmentDefinition` 与 `EquipmentModel`：头/甲/裤/包四槽、装备校验、背包超容拒绝、快照恢复。
- 新增 `EncumbranceModel`：20基础负重、100/110/125/140%四档惩罚、奔跑/翻越/游泳许可。
- 新增 `CharacterBuildModel`：属性、装备、局内 Buff、负重的统一解析顺序。
- 库存新增安全容量调整和占用槽位查询；玩家移动、奔跑体力、近战伤害和玩家快照接入构筑。
- GameManager 持有构筑并提供属性分配、装备/卸下命令；开始界面增加角色配置面板，游戏 HUD 显示负重。
- 四个装备槽各加入轻重两件资源，物品目录由22件增至30件。
- `EquipmentTransactionModel` 已接入 GameManager；E 键装备、四槽 HUD 点击卸装，固定2秒站定，移动/受击中断，失败时库存与构筑原子回滚。
- 背包 UI 会随 8/10/12 格容量重建；地下室放置头、甲、裤、包四件可拾取装备。
- 局外累计结晶阈值为 0/10/30/60/100/160，每阶奖励5点本局属性；旧局外快照缺少累计字段时按钱包结晶兼容。
- `RunSnapshotData` 持久化 `character_build_state`，旧快照缺少该字段时恢复仍兼容。
