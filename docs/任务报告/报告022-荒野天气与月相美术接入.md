## 2. 完成内容

- 在 `assets/art/` 下登记月相、雾、尘、雨和寒霜素材，记录来源、CC0 许可、下载日期与 SHA-256。
- 新增 `WorldEnvironmentPresenter`，提供 `present_survival(day_index, is_night)` 与 `present_disaster(kind, phase)` 表现接口。
- 通过确定性 `(maxi(day_index, 1) - 1) % 8` 映射 8 相月亮；白天隐藏月亮并清除夜间色调，夜晚显示月亮并应用低强度暮色。
- 将暴雨、烈日、浓雾、寒潮映射到独立覆盖层与粒子；预警强度为 `0.35`，生效强度为 `1.0`，未知/空闲灾难恢复清屏。
- 将可复用 Presenter 实例接入地下室，保持现有玩法节点、GameManager 信号和核心规则不变。
- 新增聚焦测试与地下室场景断言，覆盖月相回绕、昼夜可见性、灾难映射和强度边界。
- Presenter 在 `_ready()` 连接信号后主动读取既有昼夜和主灾难状态，避免晚于状态事件实例化时首帧回退为白天/晴天。

## 4. 接口与数据变化

- 新增表现接口：`present_survival(day_index: int, is_night: bool) -> void`。
- 新增表现接口：`present_disaster(kind: int, phase: int) -> void`。
- 新增只读查询：`get_moon_phase_index() -> int`、`get_weather_mode() -> StringName`、`get_weather_strength() -> float`。
- `WorldEnvironmentPresenter` 订阅既有 `GameManager.survival_changed` 与 `GameManager.disaster_changed` 信号。
- 初始化同步只调用 `GameManager` 既有只读方法，不新增公共接口或反向修改全局状态。
- 未修改 GameManager 公共接口、灾难规则、随机流、存档 schema、输入映射、Autoload 或第三方运行时依赖。
