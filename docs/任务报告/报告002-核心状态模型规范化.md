## 4. 接口与数据变化

- 新增 `HealthModel`：拒绝非正伤害/治疗；死亡后忽略伤害和治疗；`reset()` 恢复满血并清除死亡。
- 新增 `StaminaModel`：承载行走、奔跑、疲劳状态机；`tick()` 对非正时间步长无状态变化。
- `HealthComponent.take_damage/heal/reset/is_dead/get_health` 的公共签名保持不变。
- 玩家 `stamina_changed` 信号、输入动作和速度参数保持不变。
- 未修改存档字段、Resource schema、Autoload、场景节点路径或网络接口。
