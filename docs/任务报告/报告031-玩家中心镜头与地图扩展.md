# 报告031：玩家中心镜头与地图扩展

## 1. 任务分类

- 跨模块场景与核心体验修复。
- 关联计划：`docs/开发计划文档/计划030-玩家中心镜头与地图扩展.md`。

## 2. 问题与结论

- 地下室和终局核心原为 `1280×720`，与视口同尺寸；Camera2D 的边界范围小于视口，镜头被锁在固定位置。
- 玩家相机虽然启用，但平滑跟随会产生可见滞后，且多场景切换时没有显式抢占当前相机。
- 本轮采用严格居中跟随：相机关闭平滑与拖拽，玩家进入场景后显式 `make_current()`；地图边缘仍由 Camera2D limits 约束。

## 3. 修改文件

- `scenes/characters/player/player.gd`：新增相机运行时配置，启用、设为当前、关闭平滑和拖拽。
- `scenes/characters/player/player.tscn`：默认关闭 `position_smoothing_enabled`。
- `scripts/world/world_scene_controller.gd`：默认世界尺寸调整为 `2560×1440`，继续以墙厚 `40 px` 设置相机边界。
- `scenes/world/basement/basement.gd`、`scenes/world/basement/basement.tscn`：地下室扩展为 `2560×1440`，补齐墙体、重排出生点/出口/物资/应对点，并将正式地下室美术缩放至新空间。
- `assets/areas/basement_area.tres`：将遭遇生成点移入扩展后的可探索区域。
- `scenes/world/final_core/final_core.gd`、`scenes/world/final_core/final_core.tscn`：终局核心扩展为 `2560×1440`，补齐左右边界并重排 Boss、装置和最终出口。
- `tests/run_scene_tests.gd`：新增玩家中心镜头、相机当前状态、三张地图边界和移动跟随回归断言。
- `docs/开发计划文档/计划030-玩家中心镜头与地图扩展.md`、`docs/开发计划文档目录.md`：记录数值决策、执行记录和完成状态。

## 4. 接口与数据变化

- 未新增公共接口、Autoload、存档字段或外部依赖。
- 地图坐标和碰撞边界发生场景级变化；节点名称和交互语义保持不变。
- 数值决策：视口 `1280×720`；地下室/终局核心 `2560×1440`；慈航郊外 `3840×2160`；外围墙厚 `40 px`；相机平滑关闭。
