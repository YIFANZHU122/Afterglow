# 报告039：夜晚迷雾月相与动态刷怪

## 1. 任务概况

- 任务分类：计划任务、夜晚压力与动态敌人核心规则
- 对应计划：`docs/开发计划文档/计划037-夜晚迷雾月相与动态刷怪.md`
- 完成日期：2026-08-31
- 最终状态：已完成

## 2. 本次实现

- 动态刷怪导演独立维护动态实体、威胁成本、波次计时、失败重试和单调递增实体编号。
- 动态敌人从固定遭遇目标快照中排除，动态实体使用独立预算，击败/移除后释放成本。
- 动态导演快照记录导演计时、威胁预算、动态实体状态、下一编号和强制特殊波状态，并采用临时状态原子恢复。
- 刷新候选按迷雾覆盖、摄像头可见区域、玩家距离和地图保护点过滤；无合法点时只重试，不贴脸生成。
- GameManager 暴露月相倍率和夜间经过时间；月相接入波次频率、特殊刷新倾向和冷月敌人减速。
- 追击敌人加入特殊灰盒强化和环境速度倍率，相关运行时状态支持快照。

## 3. 接口与数据变化

- `DynamicSpawnDirectorModel.set_wave_interval_seconds`、`get_wave_interval_seconds`：供场景导演注入月相后的有效波次间隔。
- `DynamicSpawnDirectorModel.choose_spawn_point` 新增可选 `special_ratio` 参数；保留旧 `prefer_special` 调用兼容。
- `GameManager` 新增 `get_monster_spawn_multiplier`、`get_special_spawn_ratio`、`get_enemy_speed_multiplier`、`get_night_elapsed_seconds`。
- 动态导演快照新增 `threat_budget`、`next_entity_index`、`force_special_next_wave`，属于 `interaction_state.dynamic_spawn_directors` 内部字段。
- `ChaserEnemy` 新增 `set_environment_speed_multiplier`、`set_dynamic_special`；敌人快照增加环境速度和特殊状态字段。
- 未新增插件、外部依赖、Autoload 或网络层；固定遭遇与动态刷怪的存档边界保持分离。
