# 报告012：框架内容资源与 AI 交接

## 1. 任务分类

- 任务类型：跨模块框架完善、静态内容契约与开发文档
- 开发计划：`docs/开发计划文档/计划012-框架内容资源与AI交接.md`
- 关联计划：计划010 框架优先灰盒垂直切片
- 最终状态：已完成

## 2. 目标与范围

把计划010 的可运行灰盒框架推进为可由其他 AI 稳定扩展的内容工作流：外置区域资源、增加只读内容校验、提供独立验证命令，并形成真实源码 API 对照的 AI 使用手册。本次不新增武器系统、导航、地图生成、存档、网络或外部依赖。

## 3. 修改与新增文件

- 新增 `scripts/data/content_validation_model.gd`
  - 提供 `validate_spawn`、`validate_encounter`、`validate_area`、`validate_upgrade`。
  - 先校验脚本身份，再调用既有 `is_valid()`；返回空 `PackedStringArray` 表示合法。
  - 只读，不实例化实体、不操作节点树、不写运行时状态。
- 新增 `assets/areas/basement_area.tres`
  - 外置地下室 Area/Encounter/Spawn 配置。
  - 保留训练人偶、追击敌人、生成位置和目标文本。
- 修改 `scenes/world/basement/basement.tscn`
  - 根节点通过 `ExtResource` 引用外部地下室区域内容。
  - 删除原有内嵌 Area/Encounter/Spawn 子资源，保持场景组合和玩法节点不变。
- 修改 `tests/run_model_tests.gd`
  - 增加内容校验器合法、空数据、无效字段和错误脚本覆盖。
  - 修正 `Array[Resource]` 测试赋值，避免测试自身运行时错误。
- 修改 `tests/run_scene_tests.gd`
  - 验证地下室使用外部资源路径并通过内容契约校验。
- 新增 `tests/run_framework_validation.gd`
  - 验证地下室区域、伤害强化和移动速度强化资源。
- 新增 `docs/框架/Afterglow框架使用指南-面向AI.md`
  - 说明规范入口、模块边界、内容接入、公共 API、Presenter 和验证流程。
- 新增 `docs/框架/Afterglow内容契约速查表.md`
  - 汇总 Resource 字段、实体节点和快速检查单。
- 修改 `README.md`
  - 增加 AI 手册、内容速查表和框架验证入口。
- 修改 `AI项目总规范.md`
  - 将框架指南和内容契约速查表加入权威读取顺序、任务路由与相关索引。
  - 总规范版本由 1.0.0 更新为 1.0.1。
- 修改 `docs/开发计划文档/计划012-框架内容资源与AI交接.md`
  - 更新任务状态、完成日期、执行勾选和验证结果。
- 既有文件 `docs/开发计划文档目录.md` 已包含计划012条目；未处理其中旧的重复计划008条目。

## 4. 接口与数据变化

新增只读校验接口：

| 接口 | 输入 | 返回 | 状态变化 |
|---|---|---|---|
| `ContentValidationModel.validate_spawn` | `Resource` | `PackedStringArray` | 无 |
| `ContentValidationModel.validate_encounter` | `Resource` | `PackedStringArray` | 无 |
| `ContentValidationModel.validate_area` | `Resource` | `PackedStringArray` | 无 |
| `ContentValidationModel.validate_upgrade` | `Resource` | `PackedStringArray` | 无 |

新增资源路径：`res://assets/areas/basement_area.tres`。既有 Area、Encounter、Spawn 和 Upgrade schema 未改名、未增加存档字段，未来联机边界不受影响。

## 6. 风险与遗留问题

- 框架验证入口当前采用显式资源清单；新增正式区域或升级时必须同步登记测试入口。
- 既有开发计划索引包含重复的计划008条目，这是历史未提交内容，本次按要求保留未处理。
- 美术资源替换仍需后续计划；当前 Presenter 边界可承接替换，但没有正式动画、音效和特效管线。

## 7. 结论

计划012验收标准全部满足。后续 AI 可以先阅读框架使用指南，再按外部 typed Resource、内容验证入口和场景回归流程接入内容，不需要重新推断当前模块边界。
