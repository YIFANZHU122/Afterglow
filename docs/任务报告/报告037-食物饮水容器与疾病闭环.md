## 2. 修改范围

- 扩展 `ItemData` 食物、水、容器和致病配置。
- 为 `ItemStackModel` 增加容器运行时实例状态和格式 2 快照；继续读取格式 1 栈快照。
- 为 `InventoryModel`/`Inventory` 增加选中容器装水、饮水、转移和状态查询，并保持失败原子性。
- 将水源交互接入 `WaterSource` 与 `GameManager`；地下室水源明确为积水。
- 将饥饿/缺水阈值修正接入生存模型、体力模型和玩家移动。
- 扩展场景和存档集成测试，覆盖真实地下室取水和容器恢复。

## 3. 公共接口与数据变化

- `ItemStackModel.get_container_snapshot() -> Dictionary`
- `ItemStackModel.fill_container(source, amount, purified) -> bool`
- `ItemStackModel.consume_container(amount) -> bool`
- `InventoryModel.fill_selected_container/consume_selected_water/transfer_water`
- `GameManager.fill_selected_container_from_source(source_type, amount) -> bool`
- `GameManager.get_water_disease_chance(source_type) -> float`
- `SurvivalVitalsModel` 暴露体力恢复、治疗、体力消耗和移动速度修正出口。
- `StaminaModel.tick_with_modifiers(...)` 保留旧 `tick(...)` 兼容调用。

## 4. 数值基线

- 水源致病率：雨水 10%/15%/20%，流动水 20%/25%/30%，积水 35%/40%/45%（普通/困难/地狱）。
- 每单位容器饮水恢复 10 水分；生水在饮用时判定疾病，净水不判定。
- 疾病持续 240 秒，不叠层，只刷新持续时间；疾病期间消耗倍率 1.25、体力恢复倍率 0.80。
- 饥饿低于 20：体力恢复 0.80、治疗 0.70；低于 5：体力恢复 0.50、治疗阻断。
- 水分低于 20：体力消耗 1.20、移动速度 0.95；低于 5：体力消耗 1.50、移动速度 0.85。
