# 报告034：地下室 HUD 容器布局修复

## 1. 任务分类

- 既有 UI 缺陷修复与场景回归增强。
- 关联计划：`docs/开发计划文档/计划032-世界HUD布局与慈航目标显示.md`。
- 用户反馈：上版移走 Buff 后，地下室目标文本在小窗口仍然上下挤压。

## 2. 根因

- `ObjectiveLabel`、`EscapeLabel`、`DisasterLabel` 原先是 CanvasLayer 下的独立 Label，使用固定 `offset_top/offset_bottom`。
- 目标文本和逃生文本包含多行内容，实际内容高度超过固定控件高度，第二行会溢出到下一个 Label 的区域。
- 玩家生存/Buff 状态也以独立固定坐标绘制，窗口变窄时无法形成稳定的左右分区。

## 3. 修复内容

- 地下室新增 `ObjectiveStack`，目标、逃生、灾难三个 Label 改由 `VBoxContainer` 顺序布局。
- 玩家 HUD 新增 `StatusStack`，生存状态和 Buff 改由右侧 `VBoxContainer` 顺序布局。
- 两个分栏均采用半屏锚点、边距、自动换行和 `fit_content`，不再依赖手写多行高度。
- 更新地下室脚本与场景测试的节点路径。
- 场景测试新增窄视口回归，检查目标列、玩家状态列在可见逻辑视口内，且目标/逃生/灾难矩形不相交。
