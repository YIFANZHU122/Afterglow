# 报告038：制作篝火火把与基础建筑

## 1. 任务概况

- 任务分类：计划任务、跨模块核心循环与存档扩展
- 对应计划：`docs/开发计划文档/计划036-制作篝火火把与基础建筑.md`
- 完成日期：2026-08-31
- 最终状态：已完成

## 2. 本次实现

- 新增 `ProcessingStationModel`，提供篝火一个烹饪位和一个净水位，支持同时加工、材料锁定、中断恢复、稳定槽位锁定和快照恢复。
- 篝火场景接入近距离交互、燃料、点火、受击中断、烹饪/净水命令和加工状态快照。
- 火把场景接入玩家近距离判定、火机/篝火点燃、熄灭、燃烧倒计时、局部照明和快照恢复。
- 新增防雨棚与木墙场景，包含 `StaticBody2D` 碰撞体、生命值、边界/占用位置检查和快照恢复。
- 建筑位置快照改为 JSON 安全的二维数组编码，兼容内存快照和磁盘存档。
- 新增石刀、简易绷带、临时容器、篝火组件、防雨棚组件、木墙组件及七项基础配方资源。
- 物品目录、框架清单、地下室内容和存档交互状态已登记火把、建筑与新增产物。

## 3. 接口与数据变化

- `InventoryModel` / `Inventory` 新增按槽读取容器和按槽净水接口，保证加工期间不受选中槽切换影响。
- `ProcessingStationModel` 新增加工状态查询、创建快照和恢复快照接口。
- 篝火节点新增 `start_cooking`、`start_purifying`、`advance_processing`、`take_damage` 等公开命令。
- `GameManager.interaction_state` 新增 `torches` 数组；建筑状态继续使用独立 `building_state.entities` 区段。
- 新增 ItemData 资源 ID：`stone_knife`、`simple_bandage`、`temporary_container`、`campfire_kit`、`rain_shelter_kit`、`wood_wall_kit`。
- 未新增插件、外部依赖、Autoload 或网络层；存档字段均保持在已登记区段内。
