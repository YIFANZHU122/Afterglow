# 报告006：首个楼层击杀目标垂直切片

## 1. 任务分类与计划

- 任务类型：跨模块、高风险核心循环改造
- 开发计划：`docs/开发计划文档/计划006-首个楼层击杀目标垂直切片.md`
- 最终状态：已完成

## 2. 修改与新增文件

- 新增 `scripts/world/objective_progress_model.gd`：目标数量、进度和完成判定。
- 修改 `tests/run_model_tests.gd`：补充空目标、正常进度、重复完成和超额完成测试。
- 修改 `scenes/objects/training_dummy/training_dummy.gd`：新增 `defeated` 语义信号。
- 修改 `scenes/world/basement/basement.gd`：监听训练人偶击败事件，更新目标并推进会话状态。
- 修改 `scenes/world/basement/basement.tscn`：增加目标 HUD。
- 修改 `scenes/objects/transition_zone/transition_zone.gd`：增加目标完成门槛和楼层推进调用。
- 修改 `scenes/world/basement/basement.tscn`：地下室出口要求目标完成。
- 修改 `scripts/autoload/game_manager.gd`：增加 `is_objective_complete()` 查询。
- 新增计划和任务报告，更新计划索引与项目台账。

## 3. 接口与数据变化

`ObjectiveProgressModel` 提供 `register_completion()`、`is_complete()`、`get_completed_count()`、`get_target_count()`。

`TrainingDummy` 新增 `defeated` 信号；地下室目标完成后调用 `GameManager.complete_objective()`。

`TransitionZone.requires_objective_complete` 默认为 `false`，地下室出口配置为 `true`。完成目标后依次调用 `GameManager.clear_floor()`、`GameManager.start_next_floor()`，再执行原有场景切换。

## 5. 风险与遗留问题

- 当前目标只有地下室的一个训练人偶，尚未接入多目标刷怪和真正敌人 AI。
- 目标完成后暂时直接允许离开，没有奖励选择、楼层结算 UI 或资源奖励。
- 场景级真实按键/战斗自动化测试仍未建立，当前验证覆盖模型和加载路径。
