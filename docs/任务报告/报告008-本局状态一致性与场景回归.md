## 2. 修改与新增文件

- 修改 `scripts/core/run_session_model.gd`：新增 `revive()`，保存死亡前运行状态并恢复。
- 修改 `scripts/progression/run_reward_model.gd`：新增 `reset()`。
- 修改 `scripts/autoload/game_manager.gd`：持有本局奖励、提供 XP 查询/增加/重置和复活接口。
- 修改 `scenes/characters/player/player.gd`：玩家死亡和复活同步运行会话。
- 修改 `scenes/world/basement/basement.gd`：从 GameManager 读取 XP/等级，避免跨场景丢失。
- 新增 `tests/run_scene_tests.gd` 和 `tests/scene_test_runner.tscn`：场景级回归测试。
- 新增计划008并更新计划索引和项目台账。

## 3. 接口与数据变化

- `RunSessionModel.revive()`：仅 `DEAD` 可调用，恢复死亡前的活动状态。
- `RunRewardModel.reset()`：清除 XP 并恢复等级 1。
- `GameManager.add_run_xp()`、`get_run_xp()`、`get_run_level()`、`get_run_xp_to_next_level()`、`revive()`、`is_run_dead()`。
- `run_reward_changed(level, xp, xp_to_next_level)` 信号用于表现层订阅。
