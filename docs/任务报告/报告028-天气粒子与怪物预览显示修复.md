# 报告028：天气粒子与怪物预览显示修复

## 1. 问题

- 雨效果集中在屏幕中央，不能覆盖全图。
- 雪效果同样集中且遮挡画面。
- 烈日使用整屏渐变纹理，直接盖住角色和场景。
- 调试刷出的裂口动物贴图停在原点，看起来像没有刷新。

## 2. 根因与修复

- 雨、雪粒子使用球形发射区域且发射器位于中心；改为顶部 `y=10` 的全宽盒形发射区域，雨/雪透明度分别限制到 `0.55`/`0.5`。
- 烈日热浪 Shader 原先重新绘制天空渐变；改为 `hint_screen_texture` 采样当前屏幕，只输出低强度扰动，避免覆盖模型。
- 裂口动物 `Presenter` 原为普通 `Node`；改为 `Node2D`，保证 `RiftSprite` 继承敌人世界坐标。

## 5. 使用方式

启动调试运行后按 `F1`：

- 刷出裂口动物，确认怪物贴图位置和动画。
- 选择暴雨或寒潮，确认全屏从上往下的半透明粒子。
- 选择烈日，确认场景和角色仍可辨识。
