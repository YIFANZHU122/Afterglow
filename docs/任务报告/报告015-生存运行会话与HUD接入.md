## 4. 接口与数据变化

- `GameManager.start_run(difficulty: int = -1) -> bool`：无参调用仍使用普通难度；空闲时可先调用 `set_run_difficulty`。
- 新增 `GameManager.tick_survival`, `pause_run`, `resume_run`, `consume_food`, `consume_water` 和生存状态查询。
- 新增 `survival_changed`、`survival_environment_damage` 信号；UI 只读消费。
- 未新增 Autoload、Resource schema、存档字段、输入映射或第三方依赖。

## 5. 关键行为

- `GameManager` 使用 `PROCESS_MODE_ALWAYS`，暂停时能接收恢复命令。
- 暂停将 SceneTree 与生存 tick 一起冻结，恢复后从暂停前状态继续。
- 进入下一层时重置本层时钟和灾难调度，保留当前饥饿/水分。
- 环境伤害按最大生命值比例交给玩家现有 `HealthComponent`，不让 HUD 直接改血量。
- 玩家 HUD 显示饥饿、水分、第几天、白天/夜晚、风险级别和超时阶段。
- 难度在运行开始后锁定，复活、换图和退出恢复均不能修改。
