# 报告026：玩家坐标继承与地下室正式美术显示修复

## 1. 任务分类

- AnimationTree 表现层回归修复。
- Godot 原生 2D 地下室场景美术接入。
- 对应计划：`docs/开发计划文档/计划026-玩家坐标继承与地下室正式美术显示修复.md`。

## 2. 根因

玩家 `AnimatedSprite2D` 位于普通 `Node` 类型的 Presenter 下。普通 `Node` 不参与 CanvasItem 变换，导致玩家精灵不继承 `CharacterBody2D` 的世界坐标，固定显示在画布原点附近。玩家碰撞体和输入逻辑仍在运行，因此表现为“角色在左上角且无法移动”。

地下室首屏此前只有纯色 Polygon 背景和半透明环境覆盖层，没有可辨识的室内场景结构。

## 4. 修复结果

- 玩家 Presenter 改为 `Node2D`，AnimationTree、SpriteFrames 和 ActorPresenter 接口保持不变。
- 玩家精灵随玩家节点世界坐标移动；现有 WASD 场景回归继续通过。
- 地下室新增独立原生 2D 美术场景，包含地面、后墙、设备面板、顶部管线、灯具、警示条、通风口和残骸。
- 背景、美术和玩法实体使用明确 z 顺序，美术层不覆盖玩家、敌人和交互对象。

## 5. 接口与数据变化

- 没有公共接口、输入映射、核心规则、存档 schema 或 Autoload 变化。
- 仅将 Presenter 节点类型从 `Node` 调整为 `Node2D`。
