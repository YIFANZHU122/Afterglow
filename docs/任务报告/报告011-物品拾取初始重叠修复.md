# 报告011：物品拾取初始重叠修复

## 1. 任务分类

- 任务类型：小范围物品交互缺陷修复
- 开发计划：不需要；仅修改一个生产脚本并增加针对性场景回归
- 最终状态：已完成

## 2. 根因

`ItemWorld` 原先只通过 `body_entered` / `body_exited` 维护 `_player_nearby`。当玩家和物品在场景加载或物品生成时已经重叠，物理重叠可能先于脚本信号连接建立，导致 `_player_nearby` 保持 `false`。此后玩家不重新离开并进入区域时，按 `E` 不会调用拾取。

## 3. 修改文件

- 修改 `scenes/objects/item_world/item_world.gd`
  - 交互改为直接处理 `interact` 输入事件。
  - 按键发生时优先使用已有附近状态，并通过 `get_overlapping_bodies()` 补查实际玩家重叠。
  - 物品为空或背包已满时仍保持原有拒绝行为。
- 修改 `tests/run_scene_tests.gd`
  - 覆盖走近物品后拾取、原地丢弃后重新拾取和初始重叠拾取。
- 新增 `tests/pickup_overlap_test.tscn`
  - 提供玩家和石剑初始同位置的稳定回归场景。

## 4. 接口与数据变化

- 未增加公共接口、Autoload、依赖、Resource schema 或存档字段。
- `interact` 仍绑定物理键 `E`，操作方式不变。

## 6. 风险与遗留问题

- 多个可拾取物品同时重叠时，一次 `E` 仍可能依次拾取多个物品；这是原有输入轮询实现也具备的行为，未在本次修复中改变。
- `scripts/presentation/interaction_input_adapter.gd` 当前没有调用方；它属于既有文件，本次未擅自删除。

## 7. 结论

物品初始重叠或原地丢弃后的拾取已修复。玩家无需先离开物品范围再重新进入，直接按 `E` 即可尝试加入背包。
