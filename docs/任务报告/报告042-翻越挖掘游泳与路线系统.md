# 报告042：翻越挖掘游泳与路线系统

## 任务信息

- 任务类型：跨模块玩家移动能力、地形状态与路线验证
- 计划文档：`docs/开发计划文档/计划040-翻越挖掘游泳与路线系统.md`
- 执行日期：2026-09-01
- 最终状态：已完成

## 完成内容

- 统一 `40 px = 1 step` 换算，普通翻越 2 step、高位翻越 3 step、4 step 禁止。
- 新增翻越动作状态机，支持前置条件、固定耗时、体力消耗、重复拒绝和中断。
- 新增泥土/沙地/碎石/塌方挖掘模型，最多 3 step、耗时、噪音、铲子耐久和快照。
- 新增水深 0/1/2/3+ 规则，涉水减速、游泳体力、挣扎和 3 秒溺水缓冲。
- 新增路线验证器，拒绝无出口、唯一工具路线和非法 step 要求。
- 玩家命令接入空格翻越与 Z 挖掘，深水区域自动接入游泳；动作完成会更新位置/地形深度并发出噪音。
- 新增折叠铲物品、库存耐久扣减和归零移除；玩家 traversal 状态进入可选快照字段，旧快照继续兼容。
- 慈航郊外加入翻越障碍、深水和可挖塌方灰盒切片。
