- 新增 `ReleaseReadinessModel`，验证普通/困难/地狱难度、灾难槽位、快照体积和六层长局 tick。
- 新增 `AccessibilitySettingsModel`，提供文字缩放、颜色冗余、闪烁和屏幕震动强度设置及恢复。
- 新增 `LocalTelemetryModel`，只在本地聚合死亡原因和离层摘要，支持清空。
- 开始界面新增首轮控制提示，包含移动、奔跑、交互、翻越、挖掘和使用物品。
- 既有 HUD 保持文字化目标、风险、饥渴、负重、Buff 和灾难状态，不依赖单一颜色。
