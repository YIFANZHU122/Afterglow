## 3. 架构与接口变化

数据流改为：`Godot Input → PlayerInputAdapter → PlayerCommand → player.gd`。

- `PlayerCommand`：`move_direction`、`sprint_requested`、`attack_pressed`、`cycle_delta`、`selected_slot`、`drop_pressed`。
- `PlayerInputAdapter.collect_command()`：读取当前帧本地输入并返回命令快照。
- 命令只描述外部意图，不持有节点、位置、血量或背包状态。
- `player.gd` 不再直接调用 `Input.`；移动、体力、背包和攻击入口都接收命令字段。
- `cycle_delta` 限制为 `-1/0/1`；无数字键时 `selected_slot=-1`；移动方向限制长度不超过 1。

这些是内部新增接口，不改变现有玩家公共信号、输入动作名称或场景接口；命令可由未来网络输入适配器构造，但本次不实现网络层。
