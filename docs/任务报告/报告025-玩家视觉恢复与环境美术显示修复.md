# 报告025：玩家视觉恢复与环境美术显示修复

## 1. 问题

运行截图中玩家实体和 HUD 存在，但主角模型不可见；新增天空、天气和裂口动物资源也没有形成清晰的运行时主视觉。

## 2. 根因与修复

- 动画机 Presenter 的 `set_dead(false)` 对相同状态直接返回，无法把被隐藏的精灵恢复出来。现在恢复调用会明确设置 `visible = true`、白色调制、朝向和 Idle 状态。
- 玩家 `AnimatedSprite2D` 设置 `z_index = 10`，环境天空层使用受控透明度与负 z 顺序，避免表现层级互相遮挡。
- 裂口动物 Presenter 将 SVG 贴图设为主视觉，透明化旧红色 Polygon2D 回退节点。
- 场景测试增加精灵帧、可见性、长帧稳定性和裂口动物贴图断言。
