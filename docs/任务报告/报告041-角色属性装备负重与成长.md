## 完成内容

- 角色属性支持按局外结晶阶级扩展本局点数预算，保留属性守恒、上限和确认锁定。
- 装备交易接入真实运行时：装备消耗库存物品、替换时归还旧装备、背包扩容/缩容安全拒绝并可原子回滚。
- `E` 键对装备进入固定2秒站定交互；移动和受击中断，四槽装备 HUD 点击卸装并沿同一交互入口执行。
- 物品栏 UI 支持 8/10/12 格动态重建，负重和装备状态持续刷新。
- 地下室新增头盔、护甲、裤子和背包四类世界拾取来源。
- 局外累计结晶阈值为 0、10、30、60、100、160，每阶奖励5点本局属性；钱包消费不降低累计阶级。
- `RunSnapshotData` 新增可选 `character_build_state`，旧快照缺省时恢复兼容。
