# 报告027：调试控制器与美术预览工具

## 1. 任务分类

- 调试工具与表现层验证。
- 关联计划：`docs/开发计划文档/计划027-调试控制器与美术预览工具.md`。

## 2. 交付内容

- 新增 `DebugController` CanvasLayer，调试构建按 `F1` 显示/隐藏。
- 怪物预览：刷出 1/5 个裂口动物、清除预览对象；对象位于独立 `DebugPreviewRoot`，不计入正式遭遇。
- 天气预览：晴天、暴雨、烈日、浓雾、寒潮和强度滑杆；直接驱动环境 Presenter 表现。
- 灾难控制：选择灾难、预警、立即生效、解除全部；真实按钮调用现有 `GameManager` 生命周期。
- 异常/SAN：异常月相、污染天象、天象裂口、SAN 25% 和恢复正常。
- 状态诊断：显示玩家坐标、天气模式/强度和预览怪物数量。

## 6. 使用方式

1. 用 Godot 调试运行项目。
2. 进入任一世界场景后按 `F1`。
3. 先点“刷 1 个裂口动物”确认怪物素材，再从天气下拉框选择天气并拖动强度。
4. 需要验证真实灾难时选择灾难并点击“立即生效”；只想看画面时使用天气预览，不会改变正式规则。

## 7. 遗留风险

- 天气音效使用程序化 `AudioStreamGenerator`，属于可听见的调试反馈，不是最终混音资产。
- 场景测试退出时仍可能出现既有 ObjectDB 泄漏警告，退出码为 0。
