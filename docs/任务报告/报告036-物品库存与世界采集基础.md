## 2. 修改范围

新增 `ItemStackModel`、`ItemCatalog`、`WorldResourceDefinition`、`GatherableResourceModel`、可采集资源场景和四个物品/资源内容资源；扩展 `ItemData`、`InventoryModel`、`Inventory`、玩家输入、库存 HUD、世界掉落、玩家死亡掉落、`GameManager` 交互快照和运行存档 schema。

地下室新增 `basement_wood_01`、`basement_stone_01`；慈航郊外新增 `cihang_wild_food_01`、`cihang_scrap_01`。静态资源只保存定义，运行时数量、耗尽状态和物品数量均进入模型/快照。

## 3. 公共接口与数据变化

- `ItemData.is_valid() -> bool`；新增堆叠上限、单位重量、最大耐久和标签。
- `ItemStackModel.setup/create_snapshot/restore_snapshot`；快照格式版本 1，恢复通过 `ItemCatalog.get_item()` 解析稳定 ID。
- `InventoryModel` 支持 `add_quantity/can_add_quantity/get_stacks/get_total_weight`，基础容量固定 8 格；保留 `add_item/get_items` 兼容出口。
- `Inventory` 新增数量、容量、重量和新局重置 API；`drop_selected/drop_all` 现在返回完整运行时栈，玩家和掉落服务已适配。
- `GatherableResourceModel` 支持有限产出、难度丰度缩放、耗尽和稳定实体 ID 快照。
- `RunSnapshotData.CURRENT_SCHEMA_VERSION` 从 1 升至 2，读取仍接受版本 1，并在内存中归一化为版本 2；库存模型负责旧 `items` 列表迁移。
