# 报告009：战斗交互可用性修复

## 1. 任务分类与计划

- 任务类型：跨模块战斗交互修复与场景回归
- 开发计划：`docs/开发计划文档/计划009-战斗交互可用性修复.md`
- 最终状态：已完成

## 2. 根因

- 玩家攻击要求 `Inventory` 当前选中剑；新场景未拾取世界石剑时，左键输入被攻击资格检查静默拒绝。
- 追击敌人的碰撞体会在约 54 像素处与玩家分离，但原攻击范围为 42 像素，因此敌人永远无法进入接触伤害判定。
- 原场景测试直接把敌人放到玩家体内，没有覆盖真实接近过程。

## 3. 修改与新增文件

- 修改 `scenes/characters/player/player.gd`：增加场景注入的 `default_weapon`，选中槽为空时使用默认武器。
- 修改 `scenes/characters/player/player.tscn`：注入 `res://assets/items/stone_sword.tres` 作为默认石剑。
- 修改 `scripts/combat/chaser_enemy.gd`：攻击范围从 42 调整为 72，覆盖实体碰撞分离距离。
- 修改 `tests/run_scene_tests.gd`：增加真实 `attack` 输入造成伤害断言，并把追击伤害测试改为从 70 像素距离接近。
- 新增并完成 `计划009-战斗交互可用性修复.md`，更新 `docs/开发计划文档目录.md`。

## 4. 接口与数据变化

- `Player.default_weapon: ItemData`：场景注入的只读意图配置；不改变库存接口和物品数据结构。
- `ChaserEnemy.attack_range` 默认值由 42.0 调整为 72.0；伤害、速度和冷却不变。

## 6. 风险与遗留问题

- 玩家现在进入场景即可使用基础石剑，世界石剑仍可拾取并保留原有物品流程；后续若设计为纯拾取开局，可单独移除默认武器注入。
- 追击敌人仍使用直线追踪，不处理障碍寻路；本次只修复接触判定可达性。

## 7. 结论

计划009完成。玩家和追击敌人的双向伤害路径已在真实场景距离和真实攻击输入下验证可用。
