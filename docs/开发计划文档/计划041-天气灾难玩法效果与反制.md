# 计划041：天气灾难玩法效果与反制

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-31
- 任务分类：天气、灾难、地形、状态和反制核心规则
- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034至040完成

## 2. 目标

把已有天气与灾难调度从视觉和计时扩展为真实玩法，确保普通灾难至少两种应对方式、困难灾难只有一种主应对，并在多灾难并发时仍可解。

## 3. 包含

- 普通天气：晴天、阴天、雨天、烈日及昼夜组合规则。
- 环境字段聚合：水位、视野、听觉、体力、饥渴、篝火燃烧和怪物修正。
- 普通灾难：暴雨、烈日、浓雾、寒潮、怪物狂潮、刷新点迁移。
- 困难灾难：山洪决口、毒雾封锁、特殊怪入侵、猎杀者。
- 普通灾难至少两种有效应对；困难灾难生成公开且唯一的主应对设施。
- 普通/困难/地狱并发上限，困难灾难权重随难度和超时增加。
- 灾难未触发概率递增、触发后回归基线、同类冷却和组合冲突表。
- 环境聚合状态、设施进度、水位和状态效果进入快照。

## 4. 不包含

- 不新增更多灾难名称；先完整实现既定十种事件。
- 不允许地狱难度跳过可解性和属性安全上限。

## 5. 验收标准

- [x] 每种天气和灾难都有领域效果、表现反馈和测试入口。
- [x] 普通灾难两种应对均能有效降低或避开核心风险。
- [x] 困难灾难只有公开主设施能解除核心威胁，其他手段只能拖延。
- [x] 多灾难组合不会封死主应对设施和基础逃生路线。
- [x] 难度、驻留时间、连续未触发和冷却正确影响概率与权重。
- [x] 环境字段使用明确优先级和上限，不发生无限乘算。
- [x] 标准验证与每种灾难的聚焦灰盒测试通过。

## 6. 风险

- 多系统修正易重复计算，必须由单一 Environment Effect Resolver 输出最终状态。
- 地狱难度无限叠加需要性能上限和合法性筛选，不等于无限实例化表现节点。

## 7. 执行记录
