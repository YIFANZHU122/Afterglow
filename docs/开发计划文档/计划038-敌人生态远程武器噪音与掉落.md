# 计划038：敌人生态远程武器噪音与掉落

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-31
- 任务分类：战斗、AI、武器、感知和奖励核心规则
- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034至037完成

## 2. 目标

让战斗从单一追击接触伤害扩展为有处理顺序、资源成本和声音风险的生态，同时建立受预算约束的材料与结晶掉落。

## 3. 包含

- 普通追猎型、调查型、攻坚型三种职责敌人。
- 首个特殊怪采用“感光突袭者”：火把会扩大其视觉发现距离，但强光命中可令其短暂迟滞，使照明同时成为风险与反制。
- 统一 NoiseEvent：搜索 2 step、近战 4、采集 6、建设 8、枪械 16、爆炸 24。
- 枪械、弹药栈、弹匣、2 秒换弹、中断和射击冷却。
- 近战每次消耗最大体力 6%，保留安静和无弹药优势。
- 敌人掉落表、食物保底计数、材料预算和每图结晶上限。
- 普通、特殊、精英和二阶怪的威胁成本、掉落资格与快照。
- 敌人只调查声音发生位置，不从全图共享玩家实时坐标。

## 4. 不包含

- 不批量制作全部敌人和武器；首版只建立可扩展契约和最小内容集合。
- 不实现 Boss 新阶段；计划042负责最终表现与内容组合。

## 5. 验收标准

- [x] 三种普通职责在相同场景中表现出不同目标选择和脱战行为。
- [x] 枪械消耗弹药、不消耗体力、产生噪音；换弹被移动或受击中断但不丢失弹匣余弹。
- [x] 近战消耗体力，体力不足时拒绝攻击。
- [x] 声音受距离、墙体和雨天修正，不直接赋予永久追踪。
- [x] 掉落达到每图预算后停止发放对应高价值奖励。
- [x] 普通怪连续三次未掉食物后，下一次符合条件击杀触发保底。
- [x] 标准验证与夜间混合战斗实机流程通过。

## 6. 风险

- 子弹场景目前只用于训练人偶原型，不能直接当作正式玩家枪械模型。
- 敌人职责必须保持可读，特殊怪不得同时叠加过多新机制。

## 7. 本次实现

- 新增 `NoiseEventModel`，统一搜索、近战、采集、建设、枪械和爆炸的声音半径；雨天降低有效半径，敌人通过物理射线检查墙体遮挡。
- 新增 `EnemyRoleModel`，将 Hunter、Investigator、Siege 的声音偏好、目标选择和脱战距离分离为可测试规则；`ChaserEnemy` 支持职责与层级快照。
- 新增 `RangedWeaponModel` 与 `ItemData` 远程字段，玩家可装备简易手枪，自动换弹，移动/受击中断换弹；枪械射击不消耗体力并发出 16 step 噪音。
- 近战攻击现在消耗最大体力的 6%，不足时拒绝攻击，并发出 4 step 噪音；采集、加燃料、点燃火把/篝火发出对应建设或采集声音。
- 新增 `DropBudgetModel` 与 `EnemyDropService`；固定遭遇和动态刷怪各自维护食物、材料和结晶预算，普通怪连续三次未掉食物后触发保底。
- 动态刷怪按刷新点标签注入职责，特殊敌人使用独立层级；动态掉落预算写入导演快照，不污染固定遭遇目标。

## 8. 接口与数据变化

- `ItemData` 新增 `FIREARM` 类型及 `ranged_damage`、`magazine_capacity`、`reload_seconds`、`fire_cooldown_seconds`、`ammo_item_id`、`noise_strength` 字段；旧资源默认值保持兼容。
- `GameManager.noise_event_emitted` 与 `emit_noise_event(noise_event)` 成为统一声音事件入口，非法脚本对象会被拒绝。
- `Player` 快照新增 `ranged_weapon_id` 和 `ranged_weapon`；缺失字段的旧快照仍可恢复。
- 动态导演快照新增 `drop_budget`；固定遭遇奖励预算只在本次场景运行期存在，不进入固定目标计数。
- 新增物品 ID：`handmade_pistol`、`pistol_ammo`、`crystal`。
