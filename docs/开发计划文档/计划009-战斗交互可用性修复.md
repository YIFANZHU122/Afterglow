# 计划009：战斗交互可用性修复

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-23
- 任务分类：跨模块战斗交互修复与场景回归

## 2. 目标

修复当前地下室演示中玩家无法造成伤害、追击敌人无法造成接触伤害的问题，使两条战斗路径在真实空间距离下可用。

## 3. 范围

### 包含

- 为玩家提供可立即使用的默认石剑，同时保留世界掉落物拾取流程。
- 调整追击敌人的有效接触攻击距离，使其覆盖实体碰撞产生的最小间隔。
- 增加玩家近战输入和真实追击接触距离的场景回归断言。

### 不包含

- 新武器类型、攻击动画重做、障碍寻路、远程敌人重构和数值平衡扩展。

## 4. 验收标准

- [x] 未拾取世界石剑时，玩家左键攻击可对范围内敌人造成伤害。
- [x] 追击敌人从可接近距离移动后能对玩家造成伤害。
- [x] 现有模型测试、场景回归、编辑器扫描、主场景启动和 diff 检查通过。

## 5. 风险与回滚

- 默认武器会让玩家进入场景后立即具备基础攻击能力；如需恢复纯拾取开局，可移除玩家场景的默认武器资源引用。
- 攻击范围只调整追击敌人的接触判定，不改变移动速度和伤害数值。
