# 计划042：六图区域差异化与路线生成

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-31
- 任务分类：区域内容、地图生成、关卡推进与 Boss 完整流程
- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034至041完成

## 2. 目标

用六张真实不同的地图替换当前第 2 至第 5 层复用场景，使每张地图都围绕资源、敌人、天气、路线和逃生目标形成独立决策，并完成第六图 Boss 的正式可玩流程。

## 3. 区域规划

1. 地下室：封闭、低资源、教学型固定遭遇和首次逃生。
2. 慈航郊外：草原、森林、荒漠连续区域，资源采集与路线选择。
3. 淹没聚落：水深变化、屋顶翻越、净水与洪水风险。
4. 废弃工区：工具、挖掘、噪音、重型敌人和零件资源。
5. 污染林带：浓雾、毒雾、特殊怪、稀有净化与高风险补给。
6. 终局核心：Boss 三阶段、三个抑制组件、环境装置和双路线结算。

## 4. 包含

- 每图独立 Area Resource、资源预算、敌人表、天气/灾难权重和路线网络。
- 进入地图时公开出口位置、需求、关键设施和必要风险信息。
- 确定性布局变体和地图种子，不追求无限程序生成。
- 生成后验证容器、水、食物、物资、出口、基础路线、能力路线和刷新保护区。
- 地图 2 至 5 不再复用同一场景路径。
- Boss 正式行为、阶段预警、战斗路线、环境路线、混合推进和单次奖励结算。

## 5. 验收标准

- [x] 六层分别加载六个稳定场景 ID 和场景路径。
- [x] 每图至少有两种资源/路线决策，且不是纯视觉换皮。
- [x] 所有合法种子通过基础可达性、资源保底和灾难可解性验证。
- [x] 离层继承局内状态，清理地图专属篝火、建筑、灾难和水位。
- [x] Boss 三阶段不可因高伤害跳过必要阶段，双路线均可独立完成。
- [x] 整局胜利与失败只结算一次，局外奖励与评价正确。
- [x] 六图连续长局、逐层恢复和 Boss 两路线灰盒测试通过。

## 6. 风险

- 内容量较大，先使用稳定机制组合形成差异，再替换正式美术。
- 生成验证失败必须重选布局，不用强制传送或贴脸补资源修复。
