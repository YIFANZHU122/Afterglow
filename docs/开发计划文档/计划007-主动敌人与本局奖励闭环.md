# 计划007：主动敌人与本局奖励闭环

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-23
- 任务分类：跨模块、高风险战斗与成长反馈改造

## 2. 目标

在计划006的楼层目标基础上加入一个主动追击型敌人，统一敌人击败事件和 XP 奖励，形成“受到战斗压力、击败敌人、获得本局奖励、完成楼层目标、解锁出口”的最小战斗闭环。

## 3. 范围

### 包含

- 新增 `RunRewardModel`，记录本局 XP、等级和升级阈值。
- 新增追击型敌人场景，具备追踪玩家、接触伤害、死亡和击败奖励。
- 训练人偶与追击敌人统一发出 `defeated(reward_xp)` 事件。
- 地下室目标数量从 1 扩展为 2，HUD 同时显示击杀目标和 XP/等级。
- 补模型测试、场景加载和 Godot 无头验证。

### 不包含

- 局外成长、存档、Boss、安全区、迷雾和程序化地图。
- 复杂敌人 AI 状态树、远程敌人和新第三方依赖。

## 4. 接口契约

- `RunRewardModel.new(xp_per_level: int)`：正数作为升级阈值，非正数使用 1。
- `add_xp(amount: int)`：忽略非正奖励，累计 XP；达到阈值时等级递增并保留溢出 XP。
- `get_xp()`、`get_level()`、`get_xp_to_next_level()`：只读查询。
- `defeated(reward_xp: int)`：战斗实体死亡后发送一次击败奖励事件。

## 5. 验收标准

- [x] XP 模型覆盖空奖励、升级、溢出、重复调用和非法数值。
- [x] 追击型敌人能加载、寻找玩家、造成接触伤害并在死亡时发出奖励事件。
- [x] 地下室目标显示 `0/2`，击败人偶和追击敌人后变为 `2/2`。
- [x] HUD 能显示 XP 与等级，目标完成后出口仍按计划006门槛解锁。
- [x] Godot 编辑器扫描、模型测试、主场景无头启动和 diff 检查通过。

## 6. 风险与遗留

- 当前奖励只作为本局 XP/等级反馈，尚未将等级转化为属性升级选择。
- 追击敌人使用最小直线追踪，不处理障碍寻路；后续地图复杂化前需要引入明确的导航策略。
