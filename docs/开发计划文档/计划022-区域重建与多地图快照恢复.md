# 计划022：区域重建与多地图快照恢复

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-27
- 任务分类：跨模块场景目录、楼层边界存档与多地图恢复
- 设计文档：`docs/superpowers/specs/2026-08-27-world-scene-rebuild-design.md`
- 实施计划：`docs/superpowers/plans/2026-08-27-world-scene-rebuild-implementation-plan.md`

## 2. 目标

为楼层提供稳定场景目录，自动保存离层边界，并按安全退出快照重建正确地图及实体状态。

## 3. 范围

### 包含

- 1-6 层灰盒场景目录和位置校验。
- 快照 `run_session_state` 内的场景 id、路径和出生点元数据。
- `depart_floor()` 自动写入楼层边界快照。
- 恢复并切换到正确场景，动态实体组装完成后回填状态。
- 非法场景、重复恢复、边界写入失败和结算边界测试。

### 不包含

- 正式随机地图生成、云存档、旧版本迁移、网络同步和新依赖。
- 生存、灾难、Boss、库存和随机流规则调整。

## 4. 验收标准

- [x] 有效楼层均能通过目录得到场景 id、路径和默认出生点。
- [x] 离层前自动写入当前楼层边界，写入失败不会推进楼层。
- [x] 安全退出恢复能定位正确地图，错误场景不会消费 pending 状态。
- [x] 场景加载完成后玩家、敌人和交互状态继续由计划021的快照适配器恢复。
- [x] 既有标准验证全部通过。
