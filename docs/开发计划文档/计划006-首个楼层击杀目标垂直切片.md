# 计划006：首个楼层击杀目标垂直切片

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-23
- 任务分类：跨模块、高风险核心循环改造

## 2. 目标

将地下室中的训练人偶接入楼层目标系统，形成第一个可验证的垂直切片：玩家击败目标后完成楼层目标，状态进入 `OBJECTIVE_COMPLETE`，随后清除楼层并允许通过传送区域进入下一层。

## 3. 范围

### 包含

- 新增无节点依赖的 `ObjectiveProgressModel`，记录目标总数、已完成数和完成状态。
- 训练人偶死亡时向地下室报告目标完成；目标完成后调用 `GameManager.complete_objective()`。
- 传送区增加“必须完成当前楼层目标”的门槛。
- 地下室 HUD 显示目标进度，并在目标完成后提示可离开。
- 补模型测试、主场景验证和任务报告。

### 不包含

- 新敌人 AI、刷怪器、Boss、安全区、迷雾和程序化地图。
- 局外成长、存档、网络和新依赖。

## 4. 接口契约

- `ObjectiveProgressModel.new(target_count: int)`：目标数小于 0 按 0 处理。
- `register_completion()`：未完成时增加一次进度；超过目标数拒绝；返回是否发生变化。
- `is_complete()`、`get_completed_count()`、`get_target_count()`：只读查询。
- `GameManager.complete_objective()`：仅 `EXPLORING` 状态可调用。
- `TransitionZone.requires_objective_complete`：默认 `false`，地下室出口配置为 `true`；门槛未满足时不切场景。

## 5. 验收标准

- [x] 模型测试覆盖空目标、正常进度、重复完成和超额完成。
- [x] 地下室目标进度从 `0/1` 变为 `1/1` 后进入 `OBJECTIVE_COMPLETE`。
- [x] 目标未完成时传送区拒绝切换，完成后允许切换。
- [x] Godot 4.7.1 编辑器扫描、模型测试、主场景无头启动和 diff 检查通过。

## 6. 风险与遗留

- 训练人偶仍是临时敌人实体，本轮只接入目标事件，不重构其 AI。
- 目标完成暂不显示完整结算界面，后续计划再接入楼层清除和奖励选择。
