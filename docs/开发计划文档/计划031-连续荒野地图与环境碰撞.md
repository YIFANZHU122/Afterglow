# 计划031：连续荒野地图与环境碰撞

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-28
- 完成日期：2026-08-28
- 任务分类：跨模块场景、美术表现与物理碰撞功能
- 任务来源：用户确认采用单张连续地图，并要求扩大地图、加入草原/森林/荒漠和真实碰撞检测
- 设计文档：`docs/superpowers/specs/2026-08-28-continuous-wilderness-map-design.md`
- 实施计划：`docs/superpowers/plans/2026-08-28-continuous-wilderness-map-implementation-plan.md`

## 2. 目标

1. 将慈航郊外扩展为 `5760×3240` 的连续荒野地图。
2. 在一张地图中加入荒草平原、枯树林地、荒漠废墟三个连续地形分区。
3. 新增树木、岩石、废弃车辆三种带 `StaticBody2D + CollisionShape2D` 的可复用环境障碍。
4. 保留地下室入口、返回出口、玩家出生、寄生花、相机边界和存档/地图切换流程。
5. 保证北侧、南侧两条横向通路可行走，关键节点周围有无障碍缓冲。

## 3. 范围与非目标

### 包含

- `CihangTerrainArt` 地形表现层。
- 三种可复用环境障碍场景及固定实例。
- 慈航郊外地图尺寸、外围墙和关键节点坐标调整。
- 玩家阻挡、相机边界和通道清晰度回归测试。
- 数值记录、计划索引和任务报告。

### 不包含

- 不拆分为多张地形地图。
- 不引入 TileMap、运行时随机生成、导航网格、插件或新 Autoload。
- 不修改玩家移动、攻击、敌人感知、灾难、存档和地图切换领域规则。
- 不把草地、土路和沙地做成不可通行碰撞。

## 4. 数值决策

| 项目 | 数值 | 说明 |
|---|---:|---|
| 视口 | `1280×720` | 保持现有项目设置 |
| 慈航郊外地图 | `5760×3240` | 单张连续荒野地图 |
| 相机可移动宽度 | `5680` | `40..5720`，对应外围墙厚度 |
| 相机可移动高度 | `3160` | `40..3200`，对应外围墙厚度 |
| 外围墙厚度 | `40 px` | 与现有世界控制器约定一致 |
| 最小关键点缓冲 | `160 px` | 出生、入口、出口、寄生花和交互点 |
| 最小主要通道宽度 | `128 px` | 实际首版路线表现宽度为 `160 px` |
| 地形边界 | `2200 / 4200` | 草原/森林/荒漠过渡中心线 |

## 5. 验收标准

- [x] 慈航郊外 `_get_world_size()` 返回 `5760×3240`，四面墙体与背景覆盖完整。
- [x] `CihangTerrainArt` 提供草原、枯森林、荒漠废墟和两条横向路线。
- [x] 树、岩石、废车三类障碍均为 `StaticBody2D`，且拥有有效碰撞形状。
- [x] 玩家向障碍移动时不能穿过；向外围墙移动时不能越界。
- [x] 入口、出口、出生点和寄生花距障碍至少 `160 px`。
- [x] 既有玩家、敌人、拾取、灾难、存档、地图切换和相机测试继续通过。
- [x] 模型、场景、框架、存档、编辑器、主场景启动和 `git diff --check` 全部通过。

## 7. 风险与回滚条件

- 固定障碍坐标可能影响敌人刷新或后续正式资源点；优先只调整实例位置，不改变场景契约。
- 如果通道被阻塞，保持三种障碍资源不变，仅重排实例位置或缩放。
- 如果正式美术后续替换表现层，保留障碍根节点和碰撞子节点名称，避免影响测试和存档边界。
