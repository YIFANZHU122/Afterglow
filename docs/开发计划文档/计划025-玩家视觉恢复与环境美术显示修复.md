# 计划025：玩家视觉恢复与环境美术显示修复

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-28
- 完成日期：2026-08-28
- 任务分类：动画机回归修复、世界表现层级修复

## 2. 根因

- `AnimationTreeActorPresenter.set_dead(false)` 在状态值已经为 `false` 时提前返回，无法修复被死亡轨道或恢复流程隐藏的玩家精灵。
- 新增天空层未明确设置可见层级和透明度，运行时容易被全屏世界背景或其他 CanvasLayer 视觉覆盖。
- 裂口动物 Presenter 保留红色灰盒视觉，导致新增 SVG 不是主视觉。

## 3. 修复内容

- 玩家动画 Presenter 的存活恢复改为幂等：始终恢复精灵可见、白色调制、朝向和 Idle 状态。
- 玩家精灵设置明确 `z_index = 10`，环境天空层使用受控透明度与负 z 顺序。
- 裂口动物 SVG 成为主视觉，原灰盒 Polygon2D 仅保留为透明回退锚点。
- 新增玩家视觉恢复回归测试，并扩展场景测试检查精灵帧、可见性、裂口动物贴图和长帧稳定性。
