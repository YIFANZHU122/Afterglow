# 计划036：制作篝火火把与基础建筑

- 状态：已完成
- 创建日期：2026-08-31

- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034、计划035完成
- 实施计划：`docs/superpowers/plans/2026-08-31-crafting-fire-building-implementation-plan.md`

## 2. 目标

建立材料消耗与时间交换的制作体系，交付篝火、火把、烹饪、净水和最小防雨设施，使玩家能够主动准备夜晚并承担位置暴露和燃料成本。

## 3. 包含

- typed Recipe Resource、材料清单、工作站类型、制作时间和属性门槛。
- 制作任务模型：开始时锁定材料，移动、受击、体力不足或工作站失效时中断。
- 徒手配方：基础火把、石刀、简易绷带、临时容器。
- 篝火配方与放置：燃料、稳定值、照明、休息、复活点和刷怪保护半径。
- 火机必定点燃；两石取火成功率 30%，每次耗时 10 秒且失败只损失时间。
- 火把制作后未点燃，可由篝火或火机点燃、主动熄灭并保存剩余时间。
- 篝火一个烹饪位和一个净水位，可同时加工。
- 雨天不熄灭篝火，基础雨天燃烧 1.5 倍；暴雨 1.75 倍；防雨棚恢复 1.0 倍。
- 最小建筑：防雨棚和木墙，拥有生命、位置合法性和当前地图快照。

## 4. 不包含

- 不实现工作台高级配方、陷阱群、拒马和复杂基地建造。
- 不实现完整智力加点；只消费计划039将使用的属性修正接口。

## 5. 验收标准

- [x] 材料不足、背包无空间、非法工作站、重复完成和中断恢复均正确。
- [x] 篝火可放置、点燃、熄灭、补充燃料、被攻击和重新点燃。
- [x] 篝火燃料、稳定、加工队列、建筑生命和复活点正确保存恢复。
- [x] 火把照明半径和剩余燃烧时间参与统一照明状态。
- [x] 雨天、暴雨和防雨棚使用正确燃烧倍率。
- [x] 关键制作配方成功率 100%，随机失败不会阻断逃生路线。
- [x] 标准验证与一次完整“采集 -> 制作 -> 点火 -> 烹饪/净水”流程通过。

## 6. 风险

- 光源必须成为领域状态，不能根据屏幕亮度判定无月标记。
- 放置建筑需要碰撞和路径检查，不能允许封死全部出口路线。
