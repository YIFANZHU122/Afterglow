# 计划032：世界 HUD 布局与慈航目标显示

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-28
- 任务分类：跨场景 UI 表现修复
- 任务来源：地下室左上角 HUD 重叠；慈航郊外缺少当前游戏目标

## 2. 目标

1. 调整地下室目标、逃生、灾难和玩家 Buff HUD 的固定区域，保证左上角信息可读且矩形不相交。
2. 为慈航郊外补齐独立的区域目标 HUD，显示当前区域名称和探索/生存目标。
3. 保持目标内容为表现层展示，不新增全局服务、存档字段或玩法规则。

## 3. 范围与非目标

### 包含

- 地下室 HUD 节点布局与必要的自动换行/尺寸调整。
- 慈航郊外目标 HUD 节点、脚本刷新和场景接入。
- 场景回归测试、计划索引和任务报告。

### 不包含

- 不修改玩家生存、灾难、遭遇、地图、镜头、存档或升级规则。
- 不新增 Autoload、公共接口、Resource schema 或外部依赖。
- 不重构已有 HUD 内容，只调整其显示位置并补齐慈航目标文案。

| 区域 | 位置 | 内容 |

| 地下室左上 | `24..760, 24..144` | 区域目标、逃生物资、灾难状态 |

- 慈航当前没有击杀遭遇，目标文案采用探索/生存语义，不伪造击杀进度。
