# 计划030：玩家中心镜头与地图扩展

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-28
- 完成日期：2026-08-28
- 任务分类：跨模块场景与核心体验修复
- 任务来源：玩家反馈镜头未始终跟随主角，地图空间过小

## 2. 目标

1. 玩家在地图内部移动时，`Camera2D` 始终以玩家为中心，不再出现明显平滑滞后。
2. 地图边缘继续受相机边界限制，镜头不显示地图外空白，也不允许玩家穿过外围墙体。
3. 地下室与终局核心扩展为 `2560×1440`；慈航郊外保持既有 `3840×2160`，三张地图均能提供实际镜头移动空间。
4. 扩展后的背景、墙体、出生点、出口、逃生物资和灾难应对点保持在有效地图范围内。

## 3. 范围与非目标

### 包含

- 玩家相机启用、设为当前相机、严格跟随配置。
- 世界控制器相机边界和地图尺寸约束。
- 地下室与终局核心场景的背景、墙体和关键节点坐标扩展。
- 地下室正式美术层的覆盖范围扩展。
- 场景回归测试、数值文档和任务报告。

### 不包含

- 不改写玩家移动、碰撞、战斗、灾难或存档规则。
- 不新增插件、Autoload、公共存档字段或外部依赖。
- 不重构慈航郊外已有内容，仅验证其边界继续有效。

## 4. 数值决策

| 项目 | 数值 | 说明 |
|---|---:|---|
| 视口 | `1280×720` | 保持现有项目设置 |
| 地下室地图 | `2560×1440` | 视口宽高各 2 倍 |
| 终局核心地图 | `2560×1440` | 与普通可探索层保持同一空间尺度 |
| 慈航郊外地图 | `3840×2160` | 保留现有 3 倍视口尺寸 |
| 外围墙厚度 | `40 px` | 与现有碰撞和相机边界约定一致 |
| 相机平滑 | 关闭 | 玩家移动时镜头中心同步跟随；边缘由 Camera2D limits 约束 |

## 5. 验收标准

- [x] 场景测试能证明玩家相机启用、为当前相机且关闭平滑。
- [x] 场景测试能证明地下室和终局核心边界大于视口，慈航郊外边界保持合法。
- [x] 玩家在地图内部移动后，相机中心与玩家位置一致（允许浮点误差）。

- [x] 三张世界场景可加载，关键节点位于墙体内侧，既有目标/出口/存档流程不回归。
- [x] 模型测试、场景测试、框架验证、编辑器无头扫描、主场景启动和 `git diff --check` 全部通过。

## 7. 风险与回滚条件

- 扩展场景坐标可能影响敌人刷新保护、出口触发和正式美术覆盖；通过场景回归断言逐项确认。
- 若任一正式流程依赖旧坐标，保留节点名称和语义，只调整位置，不改变公共接口；必要时恢复单个节点坐标而不回退地图尺寸。
