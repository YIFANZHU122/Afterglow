## 2. 目标

让所有当前可进入的世界场景都实例化既有 `WorldEnvironmentPresenter`，保持天气、月相和昼夜表现的一致性。

## 3. 范围

### 包含

- 岐巷郊外场景接入 `WorldEnvironmentPresenter`。
- 终局核心场景接入 `WorldEnvironmentPresenter`。
- 场景回归验证两个场景都包含环境表现组件及关键节点。
- 保留 Presenter 既有首帧主动状态同步和信号订阅行为。

### 不包含

- 新增天气/月相素材、污染天象、异常月相或 SAN 规则。
- 修改 GameManager、灾难规则、战斗、Boss、存档或输入。
- 重构世界场景层级或抽取新的全局管理器。

## 4. 验收标准
