# 计划037：夜晚迷雾月相与动态刷怪

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-31
- 任务分类：夜晚、迷雾、月相、敌人生成与长期惩罚核心规则
- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034至036完成

## 2. 目标

实现游戏最具辨识度的压力循环：白天准备、夜晚迷雾扩张、不可见合法点持续刷怪、月相改变风险，以及无月黑暗受击带来的延迟惩罚。

## 3. 包含

- 夜晚 0-2、2-4、4-6 分钟三阶段迷雾扩张；白天退回固定污染区。
- 地图提供带标签的刷新点，生成前校验距离、可见性、照明和保护区。
- SpawnDirector 消费威胁预算，负责波次间隔、敌人权重、失败重试和预算释放。
- 苍月、冷月、绯月、无月七夜循环及对应视野、刷新、移速和特殊怪权重。
- 无月完全黑暗判定、一次性标记、跨地图保留、下一无月 1.5 倍预算和二阶怪预警。
- 篝火、火把、入口、出口、物资点和复活点保护区。
- 进入新地图时按区域配置生成初始敌人；白天迷雾默认不新增普通怪，阴天/雨天例外由配置驱动。
- 生成导演、迷雾阶段、标记和动态敌人进入快照。

## 4. 不包含

- 不在本计划新增完整敌人职责和枪械；使用现有追击怪和一个特殊怪灰盒验证生成规则。
- 不实现计划041的全部天气地形效果。

## 5. 验收标准

- [x] 白天、夜晚、各迷雾阶段和四类月相产生可测的不同生成行为。
- [x] 新怪不会出现在玩家可见处或任一保护区内；无合法点时延迟而非贴脸生成。
- [x] 存活敌人总成本不超过当前预算，死亡/移除后正确释放。
- [x] 动态生成不计入一次性区域击杀目标，任务守卫使用独立预算。
- [x] 无月标记只在完全黑暗受击时获得，并只强化下一次无月。
- [x] 安全退出后随机流、生成计时和下一批结果保持一致。
- [x] 标准验证与完整昼夜实机流程通过。

## 6. 风险

- 当前 EncounterController 同时管理固定遭遇和威胁预算；动态生成必须使用独立导演，避免目标计数和预算混账。
- 地图没有导航网格时只能在已验证通路附近生成，不能假设所有点都能追到玩家。

## 7. 执行记录

### 2026-08-31 启动

- 计划036已完成并通过完整验证，开始实现计划037的纯领域模型增量。
- 首批保持与现有 `SurvivalClockModel`、`SpawnProtectionModel`、`ThreatBudgetModel` 和确定性随机流兼容，先覆盖迷雾阶段、月相和无月标记规则。

### 2026-08-31 第一、二增量

- 新增 `NightFogModel`：夜晚 0-2、2-4、4-6 分钟三阶段，白天固定污染区，并提供合法迷雾判定。
- 新增 `MoonCycleModel`：苍月、冷月、绯月、无月七夜循环，提供视野、刷新倍率、特殊怪权重和冷月移速修正。
- 新增 `DarknessMarkModel`：全黑无月受击一次性标记，跨地图保留，下一次无月消费并提供 1.5 倍预算及二阶特殊怪预警。
- 新增 typed `DynamicSpawnPointDefinition` 与 `DynamicSpawnDirectorModel`：合法点过滤、保护区/可见性校验、波次间隔、权重选择、失败重试和快照。
- `GameManager` 已公开夜晚索引、迷雾阶段、月相、无月判定和黑暗标记命令，并将三类状态纳入生存快照。
- `WorldEnvironmentPresenter` 已根据夜间迷雾阶段显示渐进式迷雾覆盖，同时保留灾难浓雾表现。
- 模型、场景、Presenter、存档和编辑器验证均通过；动态敌人实体生成与完整刷新导演场景接入待下一增量完成。

### 2026-08-31 第三增量与验收

- 动态导演改为独立维护实体登记、单调递增实体编号和威胁预算；动态敌人不会进入固定遭遇快照或目标计数。
- 动态导演快照新增威胁预算、下一实体编号和强制特殊波状态；恢复采用临时模型/节点集合，失败不会破坏当前运行态。
- 刷新候选按地图迷雾覆盖、玩家摄像头可见区域和保护点逐点过滤；保护点解析支持世界场景根节点和父节点路径。
- GameManager 新增月相压力查询与夜间经过时间查询；苍月/冷月降低波次频率，绯月/无月提高特殊刷新倾向，冷月降低敌人移动速度。
- 追击敌人支持特殊灰盒强化（速度、接触伤害和最大生命），并把环境速度和特殊状态纳入敌人快照。
- Cihang 场景回归覆盖夜间生成、固定目标隔离、导演恢复和击败释放预算；模型、场景、框架、存档、编辑器和运行启动验证全部通过。
