# 计划039：角色属性装备负重与成长

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-31
- 任务分类：玩家属性、装备、携带与成长核心规则
- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034至038完成

## 2. 目标

建立智力、力量、体力三属性和头/甲/裤/包四装备栏，使角色构筑真实影响制作、战斗、负重、体力和路线能力，同时保持局内 Buff 与局外成长边界清晰。

## 3. 包含

- 新局 10 点属性分配，每项首版上限 20，战斗中禁止分配。
- 智力：制作耗时、普通配方材料节省上限和配方解锁门槛。
- 力量：近战伤害、负重上限、采集与挖掘耗时。
- 体力：最大生命、最大体力、恢复速度和高强度能力门槛。
- 头、甲、裤、包四装备槽，装备独立于普通背包。
- 无背包 8 格、普通背包 10 格、大型背包 12 格。
- 重量 100%、110%、125%、140% 四级惩罚及奔跑/能力限制。
- 装备更换 2 秒站定交互，受击中断。
- 局外结晶阶级阈值、属性点奖励、初始 Buff 与配方解锁存档。

## 4. 不包含

- 不制作大量装备内容；每槽提供两件能验证取舍的首版装备。
- 不引入随机词缀、装备强化或稀有度刷装系统。

## 5. 验收标准

- [x] 属性分配守恒、上限、非法输入和重复确认均正确。
- [x] 三属性实际影响对应模型，不由 UI 或物品名称推断。
- [x] 装备提供收益和明确代价，卸下时容量不足有可恢复处理。
- [x] 重量跨阈值时移速、体力、奔跑和能力许可同步变化。
- [x] 玩家运行时已通过统一构筑解析器消费 Buff、负重、移动、体力和近战效果。
- [x] 角色构筑快照已加入玩家快照，并保持旧快照字段兼容。
- [x] 首页属性分配 UI、GameManager 命令入口和属性确认锁定接入。
- [x] 四槽装备展示/实际换装交互（含2秒站定、受击中断）和局外结晶奖励接入。
- [x] 标准全量验证与不同构筑实机对比通过。

## 6. 风险

- 属性、Buff、装备同时影响相同数值，必须使用统一 Stat Resolver 避免散落乘算。
- 背包卸下时禁止静默删除物品，应拒绝操作或进入明确的超容状态处理。
