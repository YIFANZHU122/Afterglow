# 计划035：食物饮水容器与疾病闭环

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-31
- 任务分类：玩家生存、消耗品、容器和状态效果核心规则
- 上级计划：`计划033-完整生存游戏开发总路线.md`
- 前置依赖：计划034完成

## 2. 目标

把现有饥饿和水分计时器变成玩家可操作的资源收支系统，支持食物、水源、容器、净水、烹饪前后状态和疾病风险。

## 3. 包含

- 食物与饮水消费命令，整件消费并允许溢出浪费。
- 小份食物、普通食物、生肉、熟肉四类首版食物。
- 1/3/5 单位容器，净水和生水不可混装，支持 2 秒/单位转移。
- 雨水、流动水、积水三类水源及难度相关致病概率。
- 生肉疾病、水源病、持续时间刷新、药物解除和自然恢复。
- 饥渴阈值对体力恢复、生命恢复和环境伤害的实际影响。
- 开局无固定补给，出生区 30 秒内可取得空容器和水源，6 分钟内可达普通食物。
- 所有状态和容器内容进入运行快照。

## 4. 不包含

- 不实现篝火实体和配方 UI；净水与烹饪先通过可测试加工命令接入，计划036改由工作站驱动。
- 不实现复杂药剂、温度、毒素或多疾病叠加。

## 5. 关键规则

- 饥饿、水分上限 100；初始值 30/50。
- 基础下降速度分别为 36 秒/点和 27 秒/点。
- 1 单位净水恢复 10 水分；生肉恢复 8 饥饿并判定疾病；熟肉恢复 20 饥饿且无疾病。
- 疾病不叠层，只刷新持续时间；非法消费不扣除物品。
- 随机判定使用运行随机流，安全退出后结果可重现。

## 6. 验收标准

- [x] 玩家能从库存选择并使用食物或水，物品数量和状态值同步更新。
- [x] 背包满、容器满、容器混装、无目标水源和失败回滚均有明确拒绝结果。
- [x] 不同水源和难度产生正确疾病概率，保存恢复不重复判定。
- [x] 生存阈值实际修改体力恢复、体力消耗和移动速度，不由 HUD 直接计算。
- [x] 地图资源保底与可达性场景测试通过。
- [x] 旧存档缺少疾病字段时按健康状态恢复。
- [x] 标准验证与完整饮食流程通过。

## 7. 风险

- 消费和随机疾病必须保持原子性，避免物品扣除后状态应用失败。
- 资源保底需要场景可达性验证，不能只断言节点数量。
