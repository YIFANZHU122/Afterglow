# 计划020：荒野天气与月相美术接入

- 状态：已完成
- 创建日期：2026-08-27
- 完成日期：2026-08-27

- 设计文档：`docs/superpowers/specs/2026-08-27-wasteland-weather-moon-art-design.md`
- 实施计划：`docs/superpowers/plans/2026-08-27-wasteland-weather-moon-art-implementation-plan.md`

## 2. 目标

在不修改生存、灾难、存档和战斗规则的前提下，引入授权清晰的免费天气/月相素材，建立独立 `WorldEnvironmentPresenter`，让现有昼夜、暴雨、烈日、浓雾和寒潮状态获得“荒野墨痕”风格表现。

## 3. 范围

### 包含

- CC0 月相、雾、烟尘和粒子素材及授权清单。
- 8 相月相显示、白天/夜晚色调、灾难预警与生效强度。
- 可复用环境 Presenter 场景和地下室首个接入点。
- 聚焦测试、场景回归和标准验证。

### 不包含

- 玩家模型替换。
- 裂口动物与寄生花怪物素材接入。
- SAN 数值、异常月相玩法或污染天象规则。
- 灾难概率、持续时间、伤害、难度、随机流和存档 schema 修改。

## 4. 接口与数据影响

- 新增表现接口：`present_survival(day_index: int, is_night: bool) -> void`。
- 新增表现接口：`present_disaster(kind: int, phase: int) -> void`。
- 新增只读测试查询：月相索引、天气模式和天气强度。
- 不修改 `GameManager` 信号、公共方法、核心数据结构或存档字段。

## 7. 风险与回滚

| 风险 | 缓解 | 回滚 |
|---|---|---|
| 免费素材风格不完全统一 | 只把原图作为粒子/遮罩骨架，由 Presenter 统一调色和透明度 | 禁用纹理，保留纯色覆盖层 |
| 覆盖层降低战斗可读性 | 限制常态和预警透明度，HUD 位于更高 CanvasLayer | 从地下室移除 Presenter 实例，不影响规则 |
| 工作区存在并行修改 | 只增量编辑指定文件，不回退既有变更 | 保留新增资源与独立场景，暂停世界场景接入 |
