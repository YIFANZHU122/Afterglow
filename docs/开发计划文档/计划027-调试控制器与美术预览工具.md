# 计划027：调试控制器与美术预览工具

## 1. 基本信息

- 状态：已完成
- 创建日期：2026-08-28
- 完成日期：2026-08-28
- 任务分类：调试工具、表现层验证、场景接入

## 2. 目标

- 提供 F1 调试面板，让开发者直接预览怪物、天气、灾难、异常天象和 SAN 表现。
- 支持预览模式与真实灾难模式分离，预览对象不污染正式遭遇目标和存档。
- 在三个世界场景统一接入，实时显示当前环境状态和玩家坐标。

## 3. 非目标

- 不修改正式输入映射、战斗规则、遭遇统计、随机流、存档 schema 或 Autoload。
- 不把调试状态写入运行存档，不改变正式导出构建的默认画面。

## 4. 验收标准

- [x] 调试构建中 F1 可切换面板，非调试构建默认隐藏。
- [x] 可刷出/清除裂口动物预览对象，且不计入正式遭遇目标。
- [x] 可直接切换五种天气和强度，验证粒子、后处理和音效节点。
- [x] 可触发灾难预警、生效、推进和解除；真实模式调用现有 GameManager 生命周期。
- [x] 可触发异常月相、污染天象、天象裂口和 SAN 暗角。
- [x] 三个世界场景接入，场景测试和编辑器扫描通过。
