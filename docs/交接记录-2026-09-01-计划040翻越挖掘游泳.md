# 计划040 翻越挖掘游泳阶段交接记录

## 当前状态

计划040已于 2026-09-01 完成验收，后续开发从计划041“天气灾难玩法效果与反制”继续。

## 关键接口

- `StepTerrainModel.pixels_to_steps()` / `steps_to_pixels()`：统一 40px/step。
- `VaultActionModel.try_start()` / `advance()` / `cancel()`：翻越动作生命周期。
- `DiggingModel.try_start()` / `advance()` / `cancel()`：可挖地块和耐久生命周期。
- `WaterTraversalModel.start()` / `tick()`：水深、游泳和溺水缓冲。
- `RouteValidationModel.validate()`：基础路线和能力路线合法性检查。
- `Player.set_traversal_context()`：世界地形上下文的公开注入入口。
- `Inventory.damage_selected_durability()`：消耗当前耐久工具并在归零时移除。

## 控制

- `Space`：尝试翻越当前上下文障碍。
- `Z`：选中折叠铲后尝试挖掘当前可挖地块。
- 进入深水上下文后自动进入游泳状态。
